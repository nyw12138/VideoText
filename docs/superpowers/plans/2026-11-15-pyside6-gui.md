# PySide6 图形界面迁移实施计划

> **供执行者使用：** 按任务逐项实施并在每项完成后检查结果。任务使用复选框跟踪。

**目标：** 将 VideoText 的 Tkinter 界面迁移为 PySide6 单窗口转写工作台，保留现有转写、任务控制和 CLI 行为。

**架构：** 使用 PySide6 Widgets 实现 GUI。继续由现有 `WorkerProcess` 在后台启动独立工作进程，回调只向 `WorkerEventQueue` 写入事件；GUI 使用 `QTimer` 在主线程读取事件并更新控件。现有设置模块、请求协议、转写服务和输出格式保持复用。

**技术栈：** Python 3.11+、PySide6、pytest、ruff、现有 worker/event queue/protocol 模块。

## 全局约束

- 继续支持 Windows 10/11 和 Python 3.11 及以上版本。
- CLI 行为和 `videotext-gui` 命令名称保持不变。
- 保留现有 worker 请求协议、任务取消、设置文件位置和设置字段。
- GUI 控件只能在 Qt 主线程访问；后台线程只投递队列事件。
- 进度不展示工作进程没有提供的百分比。
- 本轮不增加任务历史、批量队列、字幕编辑、远程访问或网页界面。

---

## 文件结构与改动职责

- `pyproject.toml`：声明 PySide6 运行依赖，保持项目安装入口不变。
- `src/videotext/gui.py`：替换 Tkinter 主窗口、控件样式、任务交互和启动代码为 PySide6 实现；保留或等价迁移可被测试复用的 `build_request`、`stage_status` 和 `attempt_start`。
- `src/videotext/gui_events.py`：若 Qt 定时消费队列需要抽取纯逻辑，仅做最小接口调整；队列仍不依赖 GUI 控件。
- `tests/test_gui.py`：将 Tkinter/FakeRoot 测试替换为 PySide6 GUI 逻辑测试，并覆盖主窗口的重要状态变化。
- `tests/test_gui_events.py`：继续验证事件队列 FIFO、跨线程投递和旧任务事件过滤；原则上无需改动。
- `README.md`：更新图形界面依赖安装、启动和当前界面说明。
